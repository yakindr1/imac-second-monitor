# Старый iMac как второй монитор. Ручная настройка

ПК создаёт второй рабочий стол, Sunshine передаёт его по сети, Moonlight показывает на iMac. Окна можно переносить с основного экрана Windows на Mac. Все действия ниже выполняются на двух компьютерах вручную. ИИ, SSH и ключи доступа не нужны.

Нужны Windows-ПК, работающий iMac, мышь и клавиатура для обоих компьютеров и локальная сеть. Для первого теста лучше Ethernet. HDMI и перепрошивка не используются. Перед изменением сети и дисплеев запиши прежние значения или сделай снимки настроек.

## 1. Проверь модель и систему Mac

Открой меню Apple → «Об этом Mac». Запиши модель, год и версию macOS. Разрешение своей панели проверь в характеристиках Apple.

Пример проверен на iMac 27″ Mid 2011 с экраном 2560×1440 и уже установленной macOS Ventura 13.5.1 через OCLP. На Windows использовались Sunshine 2026.914.233613 и Virtual Display Driver 25.7.23 beta; на Mac — Moonlight 6.2.0.

**Moonlight 6.2.0 требует macOS 13 или новее.** На штатной High Sierra старого iMac эта версия не подходит. Не устанавливай Ventura или OCLP только ради совпадения с примером.

| Установленная macOS | Официальная версия с подходящим заявленным минимумом |
| --- | --- |
| 13 и новее | [6.2.0](https://github.com/moonlight-stream/moonlight-qt/releases/tag/v6.2.0), проверена в нашей связке |
| 11–12 | [6.1.0](https://github.com/moonlight-stream/moonlight-qt/releases/tag/v6.1.0) |
| 10.14–10.15 | [6.0.1](https://github.com/moonlight-stream/moonlight-qt/releases/tag/v6.0.1) |
| 10.13 High Sierra | [3.1.4](https://github.com/moonlight-stream/moonlight-qt/releases/tag/v3.1.4) |

Минимумы указаны в `Info.plist` этих версий: [6.2.0](https://github.com/moonlight-stream/moonlight-qt/blob/v6.2.0/app/Info.plist), [6.1.0](https://github.com/moonlight-stream/moonlight-qt/blob/v6.1.0/app/Info.plist), [6.0.1](https://github.com/moonlight-stream/moonlight-qt/blob/v6.0.1/app/Info.plist), [3.1.4](https://github.com/moonlight-stream/moonlight-qt/blob/v3.1.4/app/Info.plist). Версия [3.2.0 прекратила поддержку High Sierra](https://github.com/moonlight-stream/moonlight-qt/releases/tag/v3.2.0). Старые ветки из таблицы с указанным Sunshine мы не проверяли; это не обещание совместимости потока или актуальности защиты старой сборки. macOS 10.12 и старее этот гайд не охватывает. Дальнейшие названия пунктов приведены для Moonlight 6.2.0; в старых версиях они могут отличаться.

## 2. Скачай программы

| Где | Что скачать | Для чего |
| --- | --- | --- |
| Windows | [Sunshine](https://github.com/LizardByte/Sunshine/releases/tag/v2026.914.233613), установщик для своей архитектуры | Передаёт изображение |
| Windows | [Virtual Display Driver 25.7.23](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.7.23), архив `VDD.Control.25.7.23.zip` | Создаёт отдельный экран |
| iMac | Moonlight из таблицы выше, DMG для macOS | Принимает изображение |

Это версии проверенной установки, а не требование поставить их на любое железо. Перед загрузкой проверь совместимость с ОС и архитектурой своего ПК. Скачивай файлы из Assets официальных проектов. Для изображения не нужны OBS, FFmpeg и виртуальный аудиодрайвер.

На Mac открой DMG, перенеси Moonlight в «Программы» и запусти оттуда. Если система сообщает о несовместимой ОС, вернись к шагу 1. Не отключай защиту macOS ради случайной сборки.

## 3. Соедини компьютеры по сети

### Вариант А. Через домашний роутер

Подключи оба компьютера к одной домашней сети. По возможности используй Ethernet на обеих сторонах. Оставь автоматическое получение IP, шлюза и DNS. Гостевая сеть с изоляцией устройств не подходит.

На Windows открой «Параметры → Сеть и Интернет → Ethernet» и запиши IPv4-адрес подключённого адаптера. Для Wi-Fi открой свойства подключённой сети. Этот адрес понадобится в Moonlight.

### Вариант Б. Кабель напрямую между ПК и iMac

Подключи кабель к Ethernet-разъёмам обоих компьютеров. У iMac разъём находится сзади. Провод может не дать связь сразу: назначь отдельные адреса.

Ниже пример свободной подсети. Сначала проверь, что домашняя сеть, VPN и другие адаптеры уже не используют `192.168.50.*`. Если есть пересечение и непонятно, какую сеть выбрать, начни с варианта А.

| Поле | Windows Ethernet | iMac Ethernet |
| --- | --- | --- |
| IP-адрес | `192.168.50.1` | `192.168.50.2` |
| Маска подсети | `255.255.255.252` | `255.255.255.252` |
| Шлюз / Router | пусто | пусто |
| DNS | не добавлять | не добавлять |

**На Windows:** нажми Win + R, введи `ncpa.cpl`, нажми Enter. Правой кнопкой открой свойства именно подключённого Ethernet-адаптера. Выбери «IP версии 4 (TCP/IPv4) → Свойства → Использовать следующий IP-адрес». Заполни адрес и маску из таблицы. Шлюз и поля DNS оставь пустыми. Сохрани окна кнопкой «ОК».

**На Mac с Ventura:** открой «Системные настройки → Сеть → Ethernet → Подробнее → TCP/IP → Конфигурация IPv4 → Вручную». Введи адрес и маску Mac из таблицы, поле Router оставь пустым. Сохрани изменения. DNS для этого прямого соединения не добавляй. В старом интерфейсе High Sierra: «Системные настройки → Сеть → Ethernet → Конфигурация IPv4 → Вручную». [Путь для Ventura](https://support.apple.com/ru-ru/guide/mac-help/mchlp2718/13.0/mac/13.0) и [High Sierra](https://support.apple.com/ru-ru/guide/mac-help/mchlp2718/10.13/mac/10.13).

Wi-Fi Windows можно сохранить для интернета. Прямой провод сам по себе не раздаёт интернет Mac. Все загрузки удобнее закончить до теста. На время проверки провода выключи Wi-Fi на Mac: так поток не сможет незаметно уйти по беспроводной сети. После проверки его можно вернуть; автоматическое переключение путей в этот ручной сценарий не входит.

## 4. Установи и открой Sunshine на Windows

Запусти установщик Sunshine, подтверди системный запрос и заверши установку. Если установщик предлагает службу Sunshine, оставь её включённой. Уже работающий Sunshine переустанавливать не нужно.

В браузере Windows открой [локальную панель Sunshine](https://localhost:47990/). Предупреждение о сертификате относится к этой локальной панели; проверь адрес `localhost:47990`. Создай свои имя пользователя и пароль, затем войди. Эти данные не являются паролем Mac.

Если Windows запросит сетевой доступ, разреши Sunshine работу в нужной доверенной локальной сети. Если запрос был пропущен: «Безопасность Windows → Брандмауэр и защита сети → Разрешить работу приложения через брандмауэр». Разреши Sunshine для используемого профиля. Не выключай весь брандмауэр и не открывай порты на роутере. [Установка Sunshine](https://docs.lizardbyte.dev/projects/sunshine/latest/md_docs_2getting__started.html).

## 5. Сопряги Mac и ПК

1. Открой Moonlight на Mac. Для прямого провода в Moonlight 6.2.0 зайди в Settings → Advanced Settings и выключи `Automatically find PCs on the local network`. Добавь ПК вручную кнопкой добавления компьютера: введи IPv4 Windows из шага 3. Для прямого примера это `192.168.50.1`. В сети через роутер можно выбрать автоматически найденный ПК.
2. Выбери ПК. Moonlight покажет PIN.
3. На Windows в панели Sunshine открой страницу PIN. Выбери ожидающий запрос своего iMac, введи код с Mac и имя устройства, например `iMac`. Нажми `Send` («Отправить»).
4. В Moonlight открой приложение `Desktop`. Сначала достаточно увидеть основной экран Windows. Это проверка соединения, а не готовый второй экран.

Если Moonlight на старой Radeon не открывается, попробуй открыть его через Терминал Mac:

```sh
env QSG_RHI_BACKEND=opengl VT_FORCE_METAL=0 SDL_RENDER_DRIVER=opengl \
  /Applications/Moonlight.app/Contents/MacOS/Moonlight
```

Это запасной вариант запуска интерфейса с настройкой OpenGL. Полная команда проверенного потока для Radeon HD 6970M приведена в шаге 8. Для другой модели сначала используй обычный запуск. Порядок сопряжения описан в [официальном руководстве Moonlight](https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide).

## 6. Создай второй экран Windows

Распакуй **весь** архив `VDD.Control.25.7.23.zip` в постоянную папку на Windows. Сохрани рядом с программой папки `Dependencies` и `SignedDrivers`. Правой кнопкой нажми на `VDD Control.exe` → «Запуск от имени администратора». При первом запуске согласись установить Virtual Display Driver либо нажми `Install Driver`. Подтверди системное окно установки подписанного драйвера. Виртуальный аудиодрайвер для изображения не устанавливай.

Этот порядок относится к проверенному x64-пакету. Для Windows ARM нужен пакет и путь установки своей архитектуры. Не включай тестовую подпись драйверов и не удаляй виртуальные экраны других программ.

В пакете 25.7.23 по умолчанию задан один виртуальный дисплей. Открой «Параметры → Система → Дисплей». Нажми «Определить», найди физический и созданный виртуальный экран. Если второго экрана нет, сначала проверь установку в VDD Control. Если драйвер уже стоял с другой конфигурацией, не меняй число дисплеев вслепую.

Нажми Win + P → «Расширить». В настройках дисплея расположи виртуальный экран справа от основного или с удобной стороны. Физический монитор оставь основным. Выбери виртуальный экран и установи родное разрешение панели iMac. Для проверенного 27″ Mid 2011 это 2560×1440. В «Дополнительных параметрах дисплея» задай 60 Гц.

## 7. Передавай именно виртуальный экран

После установки VDD заверши пробный поток Moonlight сочетанием Ctrl+Option+Shift+Q на Mac. В панели Sunshine на Windows открой Troubleshooting, прокрути до раздела Restart Sunshine и нажми одноимённую кнопку. Дождись перезапуска панели или обнови страницу. Так новый журнал запуска будет содержать уже установленный виртуальный дисплей.

На Windows в панели Sunshine открой Troubleshooting и прокрути до раздела Logs. Найди в журнале запуска блок `Currently available display devices`. У виртуального монитора найди `friendly_name` и скопируй его `device_id` целиком, вместе с фигурными скобками. Имя и идентификатор будут своими на каждом ПК. Не копируй GUID из чужой инструкции.

Открой Configuration → Audio/Video («Аудио/Видео»). В поле Display Id (`output_name`; русский перевод «Показать Id») укажи скопированный `device_id`. В группе Advanced display device options найди Device configuration (`dd_configuration_option`, «Конфигурация устройства») и выбери `Disabled`: разрешение уже задаётся в Windows. Нажми Save, затем Apply. Активный поток может прерваться. [Значение `output_name`](https://docs.lizardbyte.dev/projects/sunshine/v2026.914.233613/md_docs_2configuration.html#output_name).

Заверши старый поток Moonlight и снова открой `Desktop`. Теперь должен показываться отдельный рабочий стол. Перетащи на него любое окно Windows. Пустой фон на iMac до переноса окна сам по себе не означает ошибку.

## 8. Настрой чёткий текст и плавность

В настройках Moonlight задай разрешение, совпадающее с виртуальным экраном Windows и панелью iMac. Начать тест можно с 1920×1080, 60 FPS и 20 Мбит/с, затем перейти к родному разрешению. Если текст мелкий, увеличь масштаб Windows; снижение разрешения сделает его менее чётким.

Для проверенного iMac 27″ Mid 2011 работал профиль **2560×1440, 60 FPS, 40 Мбит/с, H.264, программное декодирование, SDL/OpenGL**. HDR и YUV 4:4:4 были выключены. В Moonlight 6.2.0 настройка Video decoder → Force software decoding включает программный декодер; Video codec → H.264 выбирает кодек.

В меню Renderer версии 6.2.0 пункта SDL нет. Ниже команда для проверенной связки Moonlight 6.2.0, Ventura и старой Radeon. Сначала выполни сопряжение. В последней строке замени `192.168.50.1` фактическим IPv4-адресом своего Windows-ПК:

```sh
env QSG_RHI_BACKEND=opengl VT_FORCE_METAL=0 SDL_RENDER_DRIVER=opengl \
  /Applications/Moonlight.app/Contents/MacOS/Moonlight stream \
  --resolution 2560x1440 --fps 60 --bitrate 40000 \
  --video-codec H.264 --video-decoder software \
  --display-mode fullscreen --no-vsync --no-frame-pacing \
  --no-absolute-mouse --capture-system-keys always \
  --no-hdr --no-yuv444 --no-quit-after --keep-awake \
  192.168.50.1 Desktop
```

Это команда конкретного проверенного профиля. На другой панели исправь разрешение. Параметры старых веток Moonlight сначала сверь с их справкой `--help`; не переноси команду 6.2.0 вслепую. Выключенная V-Sync может давать разрывы изображения. На другой графике сначала проверь обычный аппаратный декодер. На Wi-Fi при рывках попробуй меньший битрейт. Повышение битрейта не исправляет низкое разрешение исходного рабочего стола.

## 9. Пользуйся и проверяй

При следующем запуске включи оба компьютера, войди в Mac, убедись, что Sunshine работает на Windows, и открой Moonlight → свой ПК → `Desktop`. На проверенной старой Radeon можно повторно вставить команду выше. Этот вариант не создаёт автоматический supervisor и не обещает запуск без входа пользователя.

Перетащи окно с ПК на iMac и обратно. Проверь обычный документ с мелким текстом, прокрутку и движение окна. Подключённые к Mac мышь и клавиатура могут управлять Windows. Для перемещения курсора между экранами используй относительный режим мыши Moonlight.

На Mac Alt называется Option:

- `Ctrl+Option+Shift+Z` освобождает или захватывает ввод.
- `Ctrl+Option+Shift+Q` завершает поток и возвращает к Mac, не закрывая приложения Windows.
- `Ctrl+Option+Shift+S` показывает статистику потока.

После согласованного завершения запусти поток заново. Отдельно проверь сон, пробуждение и полный запуск обоих компьютеров. В исходной установке полный запуск после выключения ещё не подтверждён.

## Если что-то не работает

| Что видно | Что проверить первым |
| --- | --- |
| ПК не появляется | Одна ли сеть; правильный ли Windows IP; работает ли Sunshine; разрешён ли он в брандмауэре |
| Показывается основной экран | `device_id` виртуального дисплея в Sunshine и повторный запуск потока |
| На Mac только пустой фон | Перетащи туда окно с ПК; проверь сторону расположения экранов |
| Мелкий текст размыт | Совпадают ли разрешения Windows, потока и панели; выбран ли режим «Расширить» |
| Рывки или задержка | Кабель, потери кадров, меньший битрейт; для старой Radeon профиль H.264 software выше |
| Чёрный экран или ошибка рендерера | Версия macOS и Moonlight; для проверенной старой Radeon команда OpenGL выше |

### Если прямой Ethernet блокирует брандмауэр

Windows может считать прямой кабель неопознанной общедоступной сетью. Не выключай защиту целиком. Сначала проверь существующее правило Sunshine. Если нужного разрешения нет, нажми Win + R → `wf.msc` → «Правила для входящих подключений → Создать правило → Настраиваемое». Выбери путь к своему `sunshine.exe` (обычно `C:\Program Files\Sunshine\sunshine.exe`), протокол «Любой». В «Область» разреши удалённый адрес только Ethernet-IP Mac; в прямом примере это `192.168.50.2`. Затем «Разрешить подключение», профиль именно этой сети и понятное имя правила. При общедоступном профиле выбери соответствующую отметку. Не используй этот пример адреса для сети через роутер: там нужен фактический адрес Mac. [Официальное описание мастера правил Windows](https://learn.microsoft.com/en-us/windows/security/threat-protection/windows-firewall/create-inbound-rules-to-support-rpc).

Чтобы отменить ручные сетевые адреса, верни Ethernet к автоматическому получению IPv4/DHCP на обеих сторонах. Чтобы убрать второй рабочий стол, верни прежнюю раскладку дисплеев Windows. Перед удалением виртуального драйвера восстанови прежний `output_name` Sunshine или очисти поле для выбора по умолчанию, сохрани и примени настройки. Не удаляй чужие драйверы и программы ради первого сбоя.

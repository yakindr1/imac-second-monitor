# Настройка iMac как второго экрана

Этот репозиторий служит инструкцией для агента с доступом к Windows и к iMac по SSH. Обычный чат без доступа к компьютерам не сможет выполнить настройку сам.

1. Прочитай [порядок настройки](docs/agent-setup.ru.md) целиком. Если пользователю нужен текст запроса, он находится в [prompt.ru.txt](docs/prompt.ru.txt).
2. Сначала обследуй компьютеры и существующее подключение. Используй уже установленные подходящие компоненты. Не запускай переустановку по умолчанию.
3. Настраивай только экран: виртуальный дисплей Windows → Sunshine → локальная сеть → Moonlight на Mac. Камера и экспериментальное персональное приложение не входят в этот сценарий.
4. Версии и адреса из примера не являются параметрами чужой машины. Обнаружь модель, ОС, графику, сетевые интерфейсы и идентификатор виртуального дисплея заново.
5. Сохрани настройки перед изменениями. Не обновляй macOS, OCLP или прошивку; не отключай защиты ОС и не удаляй чужие драйверы ради этой задачи.
6. Не запрашивай пароль в чате. Пароли, PIN и разрешения пользователь вводит в штатных локальных окнах. Ключи, сертификаты, сопряжение и журналы сеанса остаются вне репозитория.
7. Выполни настройку и проверь новое подключение. Статус «подключён» при уже работающем экране не доказывает повторное подключение. Если экран сейчас используется, согласуй его краткое отключение.
8. Сообщи результат простым языком: что работает, что должен делать пользователь при следующем запуске и какие проверки ещё не выполнены.

Подробный [старый справочник](docs/guide.ru.md) содержит дополнительные объяснения и отдельный раздел камеры. Он не заменяет порядок настройки выше.
